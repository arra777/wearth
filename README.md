# Wearth

A landing page for Wearth, a bilingual (NL/EN) yoga, community, and natural-clothing lifestyle
concept. Rooted in practice, woven into community.

This is the v1 landing page: it introduces the concept and collects early emails ahead of the
full launch (classes and the first clothing drop).

## Structure

- `index.html` — page markup, bilingual via `data-i18n` attributes
- `css/style.css` — styling (linen/moss/indigo/clay palette, Newsreader + Karla + IBM Plex Mono)
- `js/main.js` — language toggle, scroll-linked thread reveal, signup form handling

## Running locally

Open `index.html` directly in a browser, or serve the folder with any static file server:

```
npx serve .
```
